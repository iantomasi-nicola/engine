Scale test

Checks that this browser can hear your Xiaomi Mi Scale 2 and shows the raw data it sends, so the format can be verified on the real device. Nothing is saved or sent anywhere.

Chrome shows a list of nearby devices: step on the scale first (it only wakes up when someone stands on it), then pick it in the list (usually MIBFS or MIBCS; if you see no name, try the unnamed ones).
